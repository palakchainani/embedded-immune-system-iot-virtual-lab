# 🛡️ AI Embedded Immune System

## AI-Powered Virtual ET&T Laboratory

An innovative software-only simulation of an intelligent embedded system that can detect abnormal conditions, diagnose faults, isolate affected nodes, and simulate self-recovery.

---

## 🧠 How It Works

The system follows an autonomous protection cycle:

**DETECT → ANALYSE → DIAGNOSE → ISOLATE → PROTECT → RECOVER**

The software continuously simulates embedded-device parameters such as:

- Temperature
- Voltage
- Current
- Vibration

AI analyses these parameters and identifies abnormal behaviour.

---

## 🧪 Virtual ET&T Laboratory

The project provides a virtual environment where students can experiment with embedded-system conditions without requiring physical hardware.

Experiments include:

1. Thermal Stress
2. Voltage Stability
3. Vibration Analysis
4. Multi-Fault Simulation

## 💥 Fault Injection

Users can simulate different embedded-system faults:

- Thermal Runaway
- Voltage Collapse
- Excessive Vibration
- Multiple Simultaneous Faults
- Gradual System Degradation
